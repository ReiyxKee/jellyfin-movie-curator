Movie Curator

Groups every movie into its own <Original title> (<Year>) folder, fixes wrong matches (search & pick, or Suggest matches from the file names), and locks movies so batch metadata refreshes leave them alone. A locked .nfo keeps the identification with the files. Files only move when you press Apply.

Naming

Tokens: {title} (Jellyfin's title), {originalTitle} (falls back to title), {year}, {tmdb}, {imdb}. Empty brackets and dangling dashes are removed when a value is missing.

e.g. {title} - {year}, {year} - {title}, {title} ({year}) [imdbid-{imdb}]
e.g. {originalTitle} to show native titles in Jellyfin
